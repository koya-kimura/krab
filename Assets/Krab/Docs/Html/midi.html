02

ページと座標

サイドボタンはページ選択。上端を0、下端を7とし、押したページが以前のページを完全に置き換える。パッド座標は左端がx=0、下端がy=0。

APC MINI MK2 / LOGICAL MAP

0,77,7 0,07,0
P0P1P2P3P4P5P6P7
← X: 0 TO 7 →Y: BOTTOM TO TOP ↑

例: ページ1の左から2列目・下から2段目は (1, 1, 1)。パッドNote番号は y × 8 + x。

操作子番号 / 役割現在の扱い
8×8 PadNote 0–63現在ページ + (x,y) で別の割当て。RGB LED対応。
Side P0–P7Note 112–119ページ0–7を選択。ページボタン自体はBindingへ送らない。
Track T0–T7Note 100–107対応するF0–F7のnormal／割当てモードを切替。実機LEDは有効時に赤点灯。
ShiftNote 122ページ非依存のグローバルBindingとしてLearn可能。
F0–F7 + MCC 48–56現在ページ + CC番号でLearn。F0–F7はmute/randomの出力値、Masterは常に物理値。

06

生成・寿命・メソッド

SceneContainerの注入は参照を結ぶ。状態オブジェクトの生成とイベント購読は各MonoBehaviourが持ち、Scene破棄時に解除する。

所有者生成・参照破棄・解除
MidiInputManagerBindings と Adapter を初回アクセスで生成。Awake で同一GameObjectの MidiOutput とOutputAdapterを取得／生成。OnEnable で既存Minisデバイスとデバイス変更通知を購読。OnDisable で実機・出力の通知を解除。OnDestroy でBindingとページ変更通知を解除。
MidiOutputOnEnable で背景ワーカーを開始。ポート名に「APC mini mk2」を含む出力を探し、失敗時は設定間隔（初期2秒）で再試行。OnDisable で停止要求し、最大100ms待ってキューを空にする。ConnectionChanged は Update からUnityメインスレッドで通知。
MidiBindingUiConstruct でProviderのManagerを参照。CreateButton ごとにランチャーと設定Windowを作成し、開閉購読を保持。OnDestroy でBindingChangedと開閉購読を解除。別ParamのWindowが開いたら前のWindowを閉じる。
ParamSampleComponent全Actionに加え、動的Prefs list→radio、float→別レンジの接続例を登録。Sequenceは1〜16個の横スクロールボタンでpatternを編集し、無効／有効／現在位置を3色表示する。OnDestroy で各Action IDを UnregisterAction。削除した動的要素／stepを含め、Prefsの割当て記録は保持される。
UiBuilder注入された IEnumerable<IUiTarget> を Start でWindowLauncher化。UIルートの寿命に従う。MidiInputManager は列挙対象ではない。

MidiBindingManager の操作契約

メソッド / 通知条件と副作用
RegisterToggle / RegisterRadio / RegisterOneShot / RegisterMomentary / RegisterState / RegisterSequence / RegisterFloatC#登録時に種別を固定。radioとsequenceは子Bindingをまとめて所有し、永続状態とAction固有LEDを復元する。
Learn(paramId) / CancelLearn()登録済みIDに対してLearn対象を1件保持。Cancelは対象をnullへ戻す。ページボタンはAdapter内で消費されるためLearn対象にならない。
Receive(message)Learn中はNote Offを無視し、Note OnまたはCCでLearnを終了して Bind。通常時はControlが等しいBindingを探し、最初のActionだけ実行。
Bind(paramId, control)同じControlの前所有者を解除し、Prefsと各Bindingを更新する。変更ごとに BindingChanged(paramId, control) を通知。
Unbind(paramId)登録は残してControlをnullにし、Prefs上のType/Numberを-1にして変更通知。
Unregister(paramId)Scene内の登録だけを除去。Learn対象ならCancel。保存済みマッピングと色は削除しない。
GetBinding(paramId) / GetControl(paramId)未登録ならnull。UIは前者でランチャーの有効状態、後者で表示とLED色欄の可否を決める。

デバイス境界の操作契約

クラス / API動作と境界条件
ApcMiniMk2InputAdapter.OnNoteOn / OnNoteOffSideはページ選択、Trackは対応フェーダーのモード切替、Padは押下時ページを保持、Shiftは常にグローバルページとして配送する。
ApcMiniMk2InputAdapter.OnControlChangeCC 48–56の物理値を保持。F0–F7はnormalなら物理値、muteなら0、randomならbeat同期の0/1を現在ページへ送る。Masterは常に物理値。
ApcMiniMk2OutputAdapter.SetPad / SetPadRangePad 0–63をRGB SysExへ変換。色の8-bit各成分を2つの7-bitデータバイトに分割。範囲外なら送信しない。
ApcMiniMk2OutputAdapter.SetButtonTrack 100–107とPage 112–119だけNoteでオン／オフ。RGB色は扱わない。
MidiOutput.SendRaw未接続・空データ・停止中は送らない。接続中はバイト列をコピーしてキューへ積む。キューが512件を超えると古いものを捨てる。

LED更新の頻度: MidiInputManager.Update は希望色を毎フレーム再計算する。実機への送出は最大15Hzで、差分パッドは1回につき最大32件。ページ切替／再接続／Binding変更時は64パッドを一度消してから現在ページを再描画する。

07

Learn → 操作 → LED

01

ParamのMIDIを開く

各操作欄の「MIDI」からLearnを押し、実機またはシミュレーターの操作子を動かす。Noteは押下時、フェーダーはCC入力時に確定する。

02

一致するActionを実行

保存された (type, page, number) が一致したときだけActionへ届く。種別はUIではなくC#登録時に決まり、radio／sequenceは各要素を個別にLearnする。

03

現在ページを再表示

パッドはtrueで設定色、falseで25%の明るさ。ページ変更時は旧LEDを消し、選択ページの状態で塗り直す。

MIDI Outの色はRGBパッド用。トラックボタンは単色、フェーダーには可動モーターがないため、UIでParamを変えても実機フェーダー位置は動かない。
08

Sceneでの接続

現在のシーンでは SceneContainer がコンポーネントを注入し、UiBuilder が IUiTarget のウィンドウを作る。MIDIの状態表示ウィンドウは登録されない。

Common側

  • MidiOutput — RtMidi出力ポート
  • MidiInputManager — 入力、Action更新、LED同期
  • MidiBindingUi — Bindingごとの設定UI
  • ApcMiniMk2Simulator — 画面上の実機パネルとフェーダーモード設定
  • ParamSampleComponent — Action種別と代表的なUI変換例をスクロール表示

UI側

  • SceneContainer が各インターフェースを注入
  • UiBuilder + RosettaUIRoot が各 IUiTarget を表示
  • 各サンプルParam横に「MIDI」ランチャー
  • Simulatorのパッド／フェーダーからもLearnできる

09

Paramを追加するとき

新しい操作対象は、Paramの所有者となるSceneコンポーネントが安定したIDでActionを登録し、同じIDのMIDIランチャーを操作欄へ配置する。Scene破棄時には登録を解除する。

01

状態とAction

用途に合わせてtyped register APIを選ぶ。random はMidiActionではなくフェーダーモードだけに存在する。

02

登録とUI

Bindings.RegisterToggle(id, param) などで登録し、単一Bindingまたはradio／sequenceの子IDにMIDIランチャーを置く。IDは保存キーになる。

03

保存と破棄

状態変更はPrefsキャッシュだけを更新し、ディスク保存は既存の Prefs.Save 操作時だけ行う。破棄時は UnregisterAction(id) を呼ぶ。

実装例: ParamSampleComponent.cs が各Action種別、永続ID付き動的Radioリスト、Sequenceグリッド、値レンジ変換、解除をまとめて示している。
