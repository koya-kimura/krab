## 読み順

1. [制作姿勢と現在の考え](ArtisticIntent.md)：対話で確認した考え、未確定の論点、過去資料。
2. [現代VJ・ライブ映像の見取り図](Landscape.md)：実践の違いを捉えるための暫定的な整理。
3. [リファレンス台帳](References.md)：作品・道具・論文の一次ソースと、近い点・異なる点・次に見る点。

## この場所の使い方

- 個人の好みや現場経験、資料で確認した事実、調査者の解釈を区別する。
- 「似ている」だけでなく、どの関心が近いのかを残す。実装方式と見た目の類似は別に扱う。
- 映像リンクのあるページを確認したことと、動画を通して鑑賞したことを区別する。
- 新しい候補は、出典・確認状態・接点を記載する。未確認の操作方法や効果を推測で断定しない。
- 美的な好みはPinterest等の視覚資料で示す。Pinterestの具体的なボードURLは未共有。
- ここから実装を決める場合は、各機能の設計文書へ別途移す。この文書自体は仕様や実装の承認ではない。
