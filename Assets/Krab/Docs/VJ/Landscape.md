# 現代VJ・ライブ映像の見取り図

調査日：2026-11-22。現代の全体像を断定するための分類ではなく、実例を見る際の仮の地図。ソフトウェアの機能が存在することと、それが現場の主流であることは別。

## 見た目・制作・演奏・運用を分けて見る

「3D」「ジェネ」「ポン出し」は同じ種類の分類語ではない。

| 観点 | 確認すること |
|---|---|
| 見た目 | 平面／立体、具象／抽象、タイポ、写真、手描き、余白、色数、情報密度 |
| 生成方法 | 完成動画、リアルタイム描画、ライブカメラ、手描き、これらの混合 |
| 操作方法 | 一発トリガー、レイヤーの抜き差し、連続パラメータ、コード変更、手描き |
| 時間の決定 | 即興、BPM同期、シーケンス、曲固有のキュー、タイムコード |
| 音との接続 | 人が聴いて操作、音響解析、MIDI等の共有イベント、事前の共同構成 |
| 観客との関係 | 出力だけを見る、手元が見える、コードを見る、観客も参加する |
| 公演の条件 | 曲が既知／未知、リハーサル、再現性、会場設備、担当範囲 |

これらは併用できる。事前に作り込まれたリアルタイム生成をキューで呼び出す公演も、完成動画を即興的に叩く演奏もある。機材名だけでは造形や演奏観を判断できない。

## 今の自分を置くなら

対話からの暫定的な位置づけ：

- 自分で好きな2Dの造形・動きを作り込む。
- 作り込んだ振る舞いを、未知の曲にも対応できる形で手動演奏する。
- 音の翻訳や独立した対旋律に限定せず、画面全体をフィールで合わせる。
- 身体性を大切にしつつ、観客にはデザインと音楽の体験として届いてほしい。
- プリミティブ図形を核に、画像・文字・背景を扱う。
- 長期的には、ライブでの応答以外に映像自体の時間構成も扱う。

この位置は既存の実践と複数の点で重なる。自分の独自性や新規性を主張する前に、作品単位で共通点と違いを確認する。

## 実際の映像を見るときの記録

まずカメラ映像で空間と観客との関係を見て、次に画面収録で造形を見る。可能なら同じ時間帯を比べる。

1. 好き／苦手と感じた場面のタイムスタンプ。
2. 色、余白、形、文字、画像、密度のうち何が効いているか。
3. 音と映像が同時に変化しているか、異なる反復をしているか。
4. 何が事前に作られ、何が本番で判断されたか。説明がなければ不明とする。
5. 映像だけでも見続けたいか。音と合わせて初めて成立する部分はどこか。
6. 「自分の道具に欲しい機能」より先に、「自分がやりたい関係」を一文で記録する。

## 次の探索で埋めたい穴

- 現代の平面的な図形・タイポグラフィを中心とした、長尺のVJ実演。
- 短いリールや完成MVでは分からない、未知の曲への判断と引き算。
- 商業公演における即興・キュー・タイムコードの担当分担。
- VJ本人だけでなく、DJ・演奏家・観客の視点からの記録。
- Pinterestの好みと、実際に長く見続けられるライブ映像との比較。
